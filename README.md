# TEMPO WALK（TEMPO）

Apple Watch で、画面を見ずにできるインターバル速歩のワークアウトアプリです。

速歩（息が上がって「ややきつい」くらい）と緩歩（ゆっくり歩き）を3分ずつ交互に歩きます。切り替えは手首の振動で伝えるので、歩くことに集中できます。記録は屋外ウォーキングとして、GPS のルートと一緒にフィットネスとヘルスケアに保存されます。

連続記録、バッジ、目標、催促の通知はありません。いつ、どれだけ歩くかは使う人が決めます。

## 使い方

1. Apple Watch で「歩きはじめる」を押す
2. 標準のワークアウトアプリと同じように 3・2・1 のカウントダウンが入り、その間にセンサーを準備します（タップで飛ばせます）
3. 振動に合わせて歩く。終わりの時間は決めません。目安は30分以上で、30分たったら一度だけ振動で知らせます（オフにできます）
4. 立ち止まると自動で一時停止し、歩き出すと再開します（オフにできます）
5. 終えるときは ✕ を押し、「ワークアウトを終了しますか？」で「終了する」を選ぶ（「続ける」でそのまま続行）。記録は GPS のルートつきで保存されます

## 振動の合図

watchOS では振動の強さを直接変えられないため、強く感じる種類の振動を選び、長い振動は短い振動を詰めて並べて作っています。さらに強くしたいときは、iPhone の Watch アプリ →「サウンドと触覚」で「はっきり」を選んでください。

| 合図 | 振動 |
|---|---|
| 切り替え5秒前 | 強く長い振動 |
| 切り替え（速歩へ / 緩歩へ） | 長い振動 |
| 歩調テンポ（オフにできます） | 1歩ごとに強めのタップ。4歩鳴って4歩休む |
| 切り替え直後・再開後の4歩 | 歩調テンポをいちばん強い振動で鳴らす |
| 30分の目安（オフにできます） | 成功 |
| 一時停止 / 再開（立ち止まった / 歩き出したときも） | 停止 / 開始 |
| もう少し速く / 少しゆるめて（テンポがオフのとき） | クリック → 上向き / 下向き |

## 歩調テンポ（初期はオン）

速歩は毎分116歩、緩歩は96歩から始め、接地のタイミングで振動します。ずっと鳴り続けないよう、4歩鳴らして4歩休む、をくり返します。切り替えの5秒前からはテンポを止め、予告の振動と混ざらないようにしています。切り替え直後と、一時停止からの再開後は、最初の4歩をいちばん強い振動で鳴らし、そのあと4歩休んでいつもの刻みに戻ります。

「心拍で自動調整」がオンなら、テンポを心拍に合わせて30秒ごとに4歩/分ずつ変えます（速歩100〜140、緩歩80〜112）。速歩で心拍が目安より低ければ上げ、高すぎれば下げます。緩歩で心拍が下がらなければ下げます。速歩のテンポは次のセットにも引き継ぎます。

## 心拍で自動調整（初期はオン）

ヘルスケアの年齢と安静時心拍から、心拍予備能（カルボーネン法）で目安を推定します。最大心拍は Tanaka 式（208 − 0.7 × 年齢）です。

- 速歩: 心拍予備能 70% 以上（85% を超えたら「少しゆるめて」）
- 緩歩: 40% 以下

区間の始めは心拍の追従を待ちます（速歩60秒、緩歩90秒）。テンポがオンならテンポで調整し、オフなら目安から20秒以上外れたときだけ、最大1分に1回振動で知らせます。推定なので、体感を優先してください。

### 終了後の回答で学習

終了画面で「速歩はどうでしたか？」と一度だけ聞きます（答えなくても構いません）。

- 楽だった: 速歩の目安を心拍予備能で +3%（最大 80%）
- ちょうどいい: そのまま
- きつかった: 目安を −3%（最小 60%）、開始テンポを −4歩/分

速歩の開始テンポは、前回最後に落ち着いたテンポから始めます。

## 構成

```
TrotWalk Watch App/   watchOS アプリ（ワークアウト本体、単体で動作）
TrotWalk/             iOS アプリ（設定と使い方）
Shared/               両方で使う設定の同期（WatchConnectivity）
TrotWalkCore/         プラン・合図・強度ガイドのロジック（Swift Package、テストあり）
Resources/tempo.icon  アプリアイコン（Icon Composer）
project.yml           XcodeGen の設定
```

- 対応 OS: watchOS 10 / iOS 17 以降（ダブルタップでの一時停止は watchOS 11 以降）
- ワークアウト: `HKWorkoutSession` + `HKLiveWorkoutBuilder`（屋外ウォーキング）。速歩・緩歩の区間は `HKWorkoutEvent(.segment)` として残します。
- ルート: `CLLocationManager` の位置を `HKWorkoutRouteBuilder` でワークアウトに添付します。
- 自動一時停止: `CMPedometer` の歩行イベント（止まった / 歩き出した）でセッションを一時停止・再開します。

## ビルド

1. [XcodeGen](https://github.com/yonaskolb/XcodeGen) を入れる: `brew install xcodegen`
2. `project.yml` の `DEVELOPMENT_TEAM` と `APP_BUNDLE_ID` を自分のものにする
3. Xcode 26 以降を使う（アイコンが Icon Composer の `.icon` のため）
4. `xcodegen generate` で `TrotWalk.xcodeproj` を作り、Xcode で開く
5. `TrotWalkWatch` スキームを Apple Watch（または Watch シミュレータ）で実行

ロジックのテスト:

```sh
cd TrotWalkCore && swift test
```

## 参考

信州大学の研究（インターバル速歩）では、速歩と緩歩を3分ずつ、1日5セットを週4日以上、5カ月続けたところ、体力が最大20%向上し、生活習慣病の指標も改善したと報告されています。速歩は2分に短縮しても構いません。
